# Undo / Redo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-surface undo/redo in the studio — Cmd/Ctrl+Z / Shift+Z / Y — covering everything that flows through the two config stores.

**Architecture:** Snapshot-based history at the two config choke points (`updateConfig` for the editor's `siteConfig`, `saveConfig` for the library). A pure history module holds two stacks per surface; a hook wraps it; each choke point captures the pre-change snapshot (text-field edits coalesce into one step); undo/redo restore a snapshot and persist it, cancelling any pending debounced autosave. A global key handler routes to the active surface and stays inert inside text fields.

**Tech Stack:** React (pages router), Jest (node env for pure logic).

**Spec:** `docs/superpowers/specs/2026-09-14-undo-redo-design.md`

## Global Constraints

- One logical action per undo step. Structural actions are single config writes; only text-field typing coalesces (one step, committed on blur). Native browser undo owns focused text fields.
- Per-surface stacks (editor vs library). No cross-surface timeline.
- Session-only, in-memory. Depth 50 per surface.
- Jest tests run under the `node` environment (`--testEnvironment=node`) — the jsdom default trips a pre-existing `@aws-sdk` ESM transform issue for modules that import the GCS client. `common/history.js` imports nothing, so it is safe either way; run its tests with `node` env to match the repo's working convention.

### Task 1: Pure history module

**Files:**
- Create: `common/history.js`
- Test: `__tests__/history.test.js`

**Interfaces:**
- Produces:

  - `capture(h, snapshot) -> h'` — pushes `snapshot` onto `undo` (trimmed to `depth`), clears `redo`.
  - `popUndo(h, current) -> { history: h', snapshot: any | null }` — moves top of `undo` out, pushes `current` onto `redo`.
  - `popRedo(h, current) -> { history: h', snapshot: any | null }` — mirror.
  - `canUndo(h) -> boolean`, `canRedo(h) -> boolean`

test('capture pushes prev, clears redo, respects depth', () => {

  h = capture(h, 'a')
  h = capture(h, 'b')
  h = capture(h, 'c') // over depth 2 → 'a' dropped

  expect(h.redo).toEqual([])

test('undo moves top to redo and returns snapshot; redo reverses', () => {
  let h = capture(createHistory(), 'v1') // undo:[v1]
  const u = popUndo(h, 'v2')             // current state is v2
  expect(u.snapshot).toBe('v1')
  expect(u.history.undo).toEqual([])
  expect(u.history.redo).toEqual(['v2'])

  expect(r.history.undo).toEqual(['v1'])
  expect(r.history.redo).toEqual([])

```js
// common/history.js
// Pure undo/redo stacks. Snapshots are opaque (whole config objects).
export function createHistory(depth = 50) {
  return { undo: [], redo: [], depth }
}

export function capture(h, snapshot) {
  const undo = [...h.undo, snapshot]
  while (undo.length > h.depth) undo.shift()
  return { ...h, undo, redo: [] }
}

export function popUndo(h, current) {
  if (!h.undo.length) return { history: h, snapshot: null }
  const snapshot = h.undo[h.undo.length - 1]
  return { history: { ...h, undo: h.undo.slice(0, -1), redo: [...h.redo, current] }, snapshot }
}

export function popRedo(h, current) {
  if (!h.redo.length) return { history: h, snapshot: null }
  const snapshot = h.redo[h.redo.length - 1]
  return { history: { ...h, redo: h.redo.slice(0, -1), undo: [...h.undo, current] }, snapshot }
}

export const canUndo = (h) => h.undo.length > 0
export const canRedo = (h) => h.redo.length > 0
```

### Task 2: `useHistory` hook

**Files:**
- Create: `common/useHistory.js`

**Interfaces:**
- Consumes: `common/history.js`.
- Produces: `useHistory(depth = 50) -> { capture(snapshot), takeUndo(current), takeRedo(current), canUndo, canRedo }`
  - `takeUndo(current)` / `takeRedo(current)` return the snapshot to restore (or `null`).
  - `canUndo` / `canRedo` are reactive booleans (drive UI enablement).

- [ ] **Step 1: Write the implementation**

```js
// common/useHistory.js
import { useRef, useState, useCallback } from 'react'
import * as H from './history'

export function useHistory(depth = 50) {
  const ref = useRef(H.createHistory(depth))
  const [, bump] = useState(0)
  const sync = () => bump((v) => v + 1)

  const capture = useCallback((snapshot) => { ref.current = H.capture(ref.current, snapshot); sync() }, [])
  const takeUndo = useCallback((current) => {
    const { history, snapshot } = H.popUndo(ref.current, current)
    ref.current = history; sync(); return snapshot
  }, [])
  const takeRedo = useCallback((current) => {
    const { history, snapshot } = H.popRedo(ref.current, current)
    ref.current = history; sync(); return snapshot
  }, [])

  return { capture, takeUndo, takeRedo, canUndo: H.canUndo(ref.current), canRedo: H.canRedo(ref.current) }
}
```

    const el = typeof document !== 'undefined' ? document.activeElement : null

### Task 5: Keyboard handler routed to the active surface

**Files:**
- Create: `common/useUndoRedoKeys.js`
- Modify: `pages/studio/index.js` (mount the handler; wire the library handlers via `onHistoryReady`)

**Interfaces:**
- Consumes: `undoEditor/redoEditor` (Task 3), library `{ undo, redo }` (Task 4 via `onHistoryReady`).
- Produces: nothing (side effect: keydown listener).

- [ ] **Step 1: Write the hook**

```js
// common/useUndoRedoKeys.js
import { useEffect } from 'react'

// getHandlers() returns the active surface's { undo, redo }. Inert while a text
// field is focused (native undo owns those).
export function useUndoRedoKeys(getHandlers) {
  useEffect(() => {
    const onKey = (e) => {
      const mod = e.metaKey || e.ctrlKey
      if (!mod || e.key.toLowerCase() !== 'z' && e.key.toLowerCase() !== 'y') return
      const el = document.activeElement
      if (el && (el.tagName === 'INPUT' || el.tagName === 'TEXTAREA' || el.isContentEditable)) return
      const h = getHandlers()
      if (!h) return
      const isRedo = (e.key.toLowerCase() === 'z' && e.shiftKey) || e.key.toLowerCase() === 'y'
      e.preventDefault()
      isRedo ? h.redo?.() : h.undo?.()
    }
    window.addEventListener('keydown', onKey)
    return () => window.removeEventListener('keydown', onKey)
  }, [getHandlers])
}
```
